\section{Candidate sets and splits}
\label{sec:setting}

\paragraph{Candidate sets.}
\label{sec:constructions}
In the matching task the decoder is shown $K$ candidate speech signals and must
pick the one the listener attended. The candidates are inputs, not labels: the
decoder sees them, so anything in them that marks the correct one is a shortcut
that solves the task without the recording. How the candidates are built
therefore decides what the task measures, and we name each set by how it is
built. \cUnm{}: the four talkers of the trial, each standardised to zero mean
and unit variance. This is the usual choice in the literature. Standardising
removes loudness, but the four candidates are still four different recordings,
and any property beyond the mean and the variance --- skew, sparsity, the balance
between frequency bands --- can still tell them apart; on this dataset it does
(Section~\ref{sec:failures}). \cMat{}: the same four talkers after
\emph{quantile matching}. We sort each candidate's values, average the sorted
values across the four candidates, and give each candidate these averages back in
its own time order. All four then contain exactly the same set of values, so no
statistic of the values --- loudness, skew, sparsity or any other --- can tell
them apart. Each keeps its own timing, and timing is what a brain response
follows. This is the most we can remove from the audio without removing the
signal the task is about. \cSame{}: the wrong candidates are the \emph{attended
talker's own} speech, taken from other, non-overlapping parts of the same trial.
All candidates then come from one voice and one loudspeaker, so neither the
audio nor the listener's orientation can say which is correct, and chance is
exact by construction \citep{accou2021}. Trials are long enough for $K\!=\!3$ and
$K\!=\!2$. \cSameM{} applies both steps. We use \cMat{} for the four-way task
and \cSameM{} as the strictest check that the EEG follows the speech.

\paragraph{Splits.}
\emph{Within-listener}, five folds: trials are split by their audio content, so no
stimulus heard in training is heard again at test; every listener appears on both
sides. \emph{Leave-one-listener-out} (LOSO), sixteen folds: one listener is held
out, and $20\%$ of the audio content is also held out, so the test listener is new
in both identity and content. A validation set is always taken from the training
part, and each test set is scored once.

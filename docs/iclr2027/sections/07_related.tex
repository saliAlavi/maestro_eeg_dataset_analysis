\section{Related work}

Brain activity follows the speech a listener attends to \citep{ding2012,lalor2009}.
Decoders either rebuild the speech envelope from EEG and compare it with each
candidate \citep{osullivan2015}, or learn the match directly
\citep{accou2021,monesi2020,puffay2023}; a separate line decodes the direction of
attention \citep{vandecappelle2021}. Closest to our concern, \citet{rotaru2024}
showed that direction decoding on several public datasets relies largely on eye
movements rather than attention. We bring that concern to the matching task and
to several streams at once, and make the check part of training and model choice
rather than an after-the-fact test. The problem is a case of shortcut learning
\citep{geirhos2020,torralba2011,gururangan2018}. The usual fixes rebalance the
data \citep{goyal2017vqa} or train against a shortcut-only branch
\citep{cadene2019rubi}; we add a scoring function in which the shortcut is
impossible. Work on balancing modalities
\citep{wang2020gradblend,huang2022competition,wu2022greedy,peng2022ogm} evens out
how fast each stream learns; we measure each stream's effect on the decision at
test time instead. The measurement is permutation importance
\citep{breiman2001,fisher2019} and the Shapley value
\citep{shapley1953,lundberg2017,covert2020} applied to whole streams; what is new
is using it to choose models and to report every result.
Appendix~\ref{app:related} gives a longer discussion.

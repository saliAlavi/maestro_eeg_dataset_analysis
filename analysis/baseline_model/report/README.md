**Headline claim (substantiated, 16 subjects):** backward decoders (VLAAI deep + linear
reference) decode **which of the four real co-present talkers** is attended (chance **0.25
at every window**) **far above chance** — LOSO 4-way rising **0.35 → 0.50** as the window
grows 5 → 30 s, over a **flat ~0.265 null** (p<1e-10), crossing 0.40 at ~15 s. The EEG-shuffle
null is flat (no drift), the **linear decoder sits at chance** (no trivial leak), and the
innovation lifts LOSO significantly — i.e., the dataset carries real, confound-free neural
signal, clearly beating the inadmissible github baseline, with headroom for the method paper.

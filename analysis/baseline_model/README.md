# baseline_model — dataset-paper AAD baseline (backward decoders)

The **admissible, leakage-safe baseline** for the AAD dataset paper. Its job: show the
corpus carries **real, decodable EEG signal** (not noise), honestly, decisively better
than the inadmissible github model, while deliberately leaving headroom below the team's
held-back multimodal method (separate paper).

## The baseline in one paragraph
We decode **which of the four real co-present talkers** (loudspeakers 1–4) the listener
attends — so chance is **0.25 at every decision window** (5 s or the whole ~30 s trial).
The decoder is a **backward (stimulus-reconstruction) model** — reconstruct the attended
talker's envelope from EEG, then decide by **scale-free correlation** against the four real
candidates (permuted slots):
- **VLAAI** — a modern deep residual-convolutional reconstruction net (headline);
- **Linear** — the classic single-Conv1d decoder (canonical reference floor).

The two dataset confounds are defused **architecturally**: loudness by the scale-free
correlation; the deterministic attended schedule by permuting the candidate slots per
(subject,trial) (the model has no audio→label path). The **EEG-shuffle null** then verifies
chance, and it is **flat across windows** (no drift). We headline the **4-way** accuracy
(chance 0.25) and report a **decision-window curve** (train 5 s, evaluate 5 → 30 s), plus a
causal-lag control every run.

> Headline (LOSO, VLAAI + multiband + margin): **4-way 0.35 → 0.50** as the window grows
> 5 → 30 s, over a flat ~0.265 null (theoretical chance 0.25), Δ +0.08 → +0.23, all p<1e-10.
> A contrastive model (*NeuroCLIP*, `models/model.py`) was also tried and sat at the null;
> envelope tracking here is detected by backward decoders. See `docs/DESIGN.md`, `report/`.

## Run
```bash
cd analysis/baseline_model/models
python train_bwd.py --smoke                                    # both models, sanity (null ≈ 0.25)
# GPU arrays (array 1-16):
sbatch ../slurm/bwd_within.sbatch                             # linear+vlaai, within
sbatch ../slurm/bwd_loso.sbatch                              # linear+vlaai, loso
sbatch ../slurm/bwd_innov_within.sbatch                     # vlaai +multiband(+margin), within
sbatch ../slurm/bwd_innov_loso.sbatch                      # vlaai +multiband(+margin), loso
sbatch ../slurm/curve_array.sbatch                        # headline 4-way decision-window curve
python aggregate.py                                      # -> report/summary.md + curve.md
```

## Honesty guarantees (see docs/DESIGN.md §5)
- **Structural chance 0.25 at every window:** four real co-present talkers → number of
  choices never changes with window; the EEG-shuffle null is flat across windows (no drift).
- **Confounds defused architecturally:** scale-free correlation kills loudness; per-(subject,
  trial) slot permutation + no audio→label path kills the deterministic schedule.
- **Proper alignment reused:** reads the method paper's `*_pa2_af64.npz` cache (inter-stream
  lags resolved once); train/val trial-disjoint in both within and LOSO.
- **Honest eval:** trial-level splits; inner-val early stop from train only; single held-out
  test eval; BatchNorm-free (no subject-stat leak).
- **Baked-in tripwires:** EEG-shuffle null (flat ~0.25–0.26) + causal-lag curve, every run;
  the **linear decoder sits at chance**, proving there is no trivial leak.
